# Changelog

## 1.0.0

- Tema de iconos **8bit Icons** para el explorador, con arte pixel art de 16×16.
- Más de 70 iconos y 229 extensiones: lenguajes, web, datos, configuración,
  medios, fuentes, comprimidos, Docker, Git y documentos.
- Siglas de 3×5 píxeles y sprites dibujados píxel a píxel; SVG con
  `crispEdges` para conservar los bordes duros.
- Tema de color **8bit Dark** a juego.
- Lámina del set completo y captura en uso en `assets/`.
- Generador único en `scripts/build-icons.js` + motor en `scripts/pixel-art.js`.
